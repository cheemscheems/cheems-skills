# 对比数值与数据来源溯源

## 一、来源三分法

对每一个对比数值、基线、数据集与关键声明，标注为：**作者自跑 / 取自已发表 / 未说明**。

判定顺序：
1. 论文自述（如 "obtained from the cited publications"、"evaluated across five random seeds"）。
2. 能否自证（自建数据集不可能存在已发表值）。
3. 到**被引原始论文**中查证：下载原文、提取表格、逐格比对。
4. 与该领域的**主要基准表**交叉核对。

## 二、全量核验流程（禁止抽查）

1. 建表：列出所有对比行与单元格。
2. 逐个定位来源：哪篇论文、哪张表、哪个 split、哪种指标口径。
3. 逐格比对：完全一致 / 部分一致 / 找不到。
4. 统计覆盖率（N/N），写入报告。
5. 对"找不到"的：列出**查证过的来源清单与排除理由**，标为"未说明／无法追溯"。

## 三、必须同时核查的三件事

- **(a) 数值来源**（三分法）。
- **(b) 作者是否逐行标明出处**：表内是否有引用标记或来源列；表注是否点名；正文引用是**逐行**还是**一句打包**；是否有的行完全没有引用。
- **(c) 引文是否真的包含该数据**：被引原文里是否存在该数据集的结果。

## 四、常见问题类型

- **打包引用**：一句引用覆盖多行，不区分行。
- **引用归属错误**：引用 A，数值实际来自 B 的对比表。
- **源头缺失**：所引原文根本没有该数据集的结果。
- **名称不一致**：表中模型名与来源表不同（如 PURE vs SciB）。
- **口径不一致**：strict vs relaxed、micro vs macro、单次 vs 多种子。
- **同模型跨表数值不同**且未解释（自跑 vs 已发表）。

## 五、报告输出

- 逐行表：编号｜行｜稿件数值｜实际出处｜判定（完全一致／部分一致／未找到）。
- 覆盖率：如 "11/11 行逐格核验"。
- "未说明"清单 + 查证范围。
- 修复要求：逐行标注来源（论文 + 表号 + split + 口径）；无法追溯者须提供原始来源或复现配置。
