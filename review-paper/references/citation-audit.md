# 引用与书目双层核验

将“正文引用支持什么”与“文末条目写得是否准确”分别查，不能用格式检查代替内容核验。

## 编号—语义对应

1. 提取当前版本完整参考文献映射；author-year 制保留年份后缀，数字制展开引用范围。核查缺号、重号、悬空引用、未引用条目与编号粘连；可疑 OCR 编号回看原页。
2. 逐处记录正文句子／表中方法、引用标记及实际条目。区分方法原作、数据集、软件、后续改进与实验数值来源。
3. 读被引文献相关内容，判断是否支持具体论述，而不只匹配标题关键词。结果引用、方法首创归因、综述转引分别标记。
4. 若用户要求全部 [1]—[N] 核验，保留每项已查／部分核验／未获得记录，不抽样后称全部通过。长任务分批推进，不因前几项已有错误而停止。

## 元数据核验

优先出版社／会议正式页面、DOI 注册记录、论文原版、官方论文集或 arXiv 版本记录。学术索引作为定位与交叉核对；搜索摘要不能代替原文验证语义。
- 作者：拼写、顺序、姓／名、连字符、变音符、团队作者；et al. 按适用体例判断，不能一概当错。
- 标题：先核对实际词语与副标题，再判断大小写体例。保留 BERT、RoBERTa 等专名。合法 sentence case 与 title case 不应被当成事实错误。
- 日期：区分 online-first、卷期出版、会议年、预印本初版和更新日期。不要强迫预印本全部替换为正式版；引文的实际版本与论述应一致。
- 刊物／会议／工作坊／书章类型、全称／认可缩写、卷期、页码或文章号、出版者、DOI/arXiv ID 逐项核对。正式版与预印本可不同，不能拼接成混合条目。
- DOI 应解析到同一论文；条目要求取决于适用体例／投稿指南。没有要求时，缺 DOI 是完整性建议，不自动是硬错误。

更正时给对应来源链接和必要原文信息，避免凭记忆“纠正”。如果用户禁止联网，就使用已提供来源并标明未独立核验。
检索不到只表示未核实，不能判定不存在或伪造。改变题名、作者、年份等组合继续定位，仍不可得则保留待核验项。

## 输出

按需求用“位置／编号｜稿件写法或用途｜核实结果｜错误类型｜建议与来源”表。把已确认错位、元数据事实错误、体例问题和未核实条目分开。编号修复限定到当前版本，不沿用历史编号。
